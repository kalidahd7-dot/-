# 📖 مقرأة الإمام الجزري - بوت تيليجرام

بوت Telegram لخدمات الإقراء والإجازة بالسند.

## المميزات
- 📚 البرامج التعليمية (القاعدة النورانية، التلاوة، الحفظ، حفص والإجازة، القراءات)
- 👨‍🏫 التعريف بالمقرئين وتخصصاتهم
- ⏱️ نظام رصيد الدقائق
- 💳 شراء الباقات
- 📅 حجز الجلسات
- 📜 الإجازات والشهادات
- 📞 الدعم والمساعدة

## المتطلبات
- Node.js 18 أو أحدث
- توكن بوت من @BotFather

## التشغيل المحلي
1. انسخ `.env.example` إلى `.env`
2. ضع `BOT_TOKEN` داخل `.env`
3. ثبّت الحزم:
   npm install
4. شغّل البوت:
   npm start

## النشر على Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables:
  - `BOT_TOKEN` = توكن البوت من BotFather
  - `PORT` = 3000 (اختياري)
